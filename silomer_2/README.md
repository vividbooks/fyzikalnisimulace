# Siloměr 2 kg

Interaktivní simulace siloměru se závažím **2 kg**. Zavěs závaží na háček a sleduj natažení pružiny a posun ukazatele na stupnici.

## Spuštění

```bash
npm start
```

Aplikace běží na [http://localhost:3475](http://localhost:3475).

## Ovládání

- **2 kg** — zavěsí závaží (pružina se roztáhne, ukazatel ukáže 20 N)
- **Sundat závaží** — vrátí siloměr do klidového stavu

## Soubory

- `assets/silomer-empty.svg` — siloměr bez zátěže
- `assets/silomer-loaded.svg` — siloměr se zavěšeným závažím 2 kg
